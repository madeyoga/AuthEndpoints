# Security Policy

## Reporting a Vulnerability

To report a vulnerability or a security-related issue, please [privately report it via the Security tab](https://github.com/madeyoga/AuthEndpoints/security/advisories/new) with the details of the vulnerability. 
If that is impossible, feel free to send an email to [madeybog@gmail.com](mailto:madeybog@gmail.com) instead. We will respond swiftly to fix verifiable security issues.

All security vulnerabilities will be promptly verified and addressed.

**Do not file public issues on GitHub for security vulnerabilities**. 
Security vulnerabilities should be reported privately, to minimize attacks against current users of AuthEndpoints package before they are fixed.
