Each guide is one task. Examples use the password facade prefix `/auth`, unless a section names another prefix. The 3.x facade uses `/identity` for account routes and `/account` for passkeys. See [Password auth](/modules/password-auth) and [3.x facade](/getting-started/compatibility-facade).

Not sure which call to make? See [Choose your sign-in setup](/getting-started/choose-a-sign-in-stack).

Coming from `MapIdentityApi`? See [What MapIdentityApi maps](/concepts/compare#what-mapidentityapi-maps). [Shared routes side by side](/concepts/compare#shared-routes-side-by-side) compares register, login, reset, and 2FA.

## I want to

| Guide | Use it when |
| --- | --- |
| [Register users](/guides/registration) | You need sign-up with a password, a passkey, GitHub, or Google. |
| [Sign users in](/guides/sign-in) | You need sign-in with a password, a passkey, an emailed code, GitHub, or Google. |
| [Turn on two-factor authentication](/guides/two-factor) | Users need authenticator codes and recovery codes. |
| [Reset a forgotten password](/guides/reset-password) | A user cannot sign in and needs a reset email. |
| [Add, rename, and remove passkeys](/guides/manage-passkeys) | A signed-in user manages their passkeys. |
| [Sign in with an emailed code](/guides/email-code) | You need a one-time code. Sign-up and the magic link stay off until you enable them. |
| [Add GitHub or Google](/guides/registration#register-with-github-or-google) | You add an external provider. Neither facade maps it. |
| [Require step-up before sensitive actions](/guides/step-up) | An endpoint returns `401` or `403` until the user proves their identity again. |
| [Run an app with no public sign-up](/guides/internal-app) | Accounts are created by an admin. There is no public register route. |
| [Upgrade to 4.0](/guides/upgrading-to-4) | You are moving a 3.x host to 4.0. |
| [Sign users out](/guides/sign-out) | You need logout for the cookie, Identity bearer, or JWT stack. |
| [Change a user's email or password](/guides/manage-account) | A signed-in user changes their email or password. |
| [Link and unlink GitHub or Google accounts](/guides/link-external-accounts) | A signed-in user connects or disconnects a provider login. |
| [Call the API from a browser](/getting-started/browser-clients) | You set up cookies, CSRF tokens, and CORS for a browser client. |
| [Prepare for production](/concepts/production) | You are about to deploy. |

Route tables for every module are in the [Endpoint reference](/modules/endpoints). The password facade route list is the [composition table](/modules/composition).
