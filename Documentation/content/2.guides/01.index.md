Each guide covers one task. The steps use the facade defaults: management and sign-in under `/identity`, passkeys under `/account`, JWT under `/auth`, and external OAuth under `/auth/external`.

Coming from `MapIdentityApi`? See [Stock Identity endpoints vs AuthEndpoints](/concepts/stock-identity-vs-authendpoints).

| Guide | Use it when |
| --- | --- |
| [Register users](/guides/registration) | You need sign-up with a password, a passkey, or GitHub or Google. |
| [Sign users in](/guides/sign-in) | You need sign-in with a password, a passkey, or GitHub or Google, including 2FA codes. |
| [Sign users out](/guides/sign-out) | You need logout for the cookie, Identity bearer, or JWT stack. |
| [Turn on two-factor authentication](/guides/two-factor) | Users need authenticator codes and recovery codes. |
| [Reset a forgotten password](/guides/reset-password) | A user cannot sign in and needs a reset email. |
| [Change a user's email or password](/guides/manage-account) | A signed-in user changes their email or password. |
| [Add, rename, and remove passkeys](/guides/manage-passkeys) | A signed-in user manages their passkeys. |
| [Link and unlink GitHub or Google accounts](/guides/link-external-accounts) | A signed-in user connects or disconnects a provider login. |
| [Require step-up before sensitive actions](/guides/step-up) | An endpoint returns `401` or `403` until the user proves their identity again. |
| [Call the API from a browser](/guides/browser-clients) | You set up cookies, CSRF tokens, and CORS for a browser client. |
| [Prepare for production](/guides/production) | You are about to deploy. |

Route tables for every module are in the [Endpoint reference](/modules/endpoints).
