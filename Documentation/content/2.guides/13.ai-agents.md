---
title: Use the AuthEndpoints skill with coding agents
description: Add the AuthEndpoints skill to your app so that coding agents follow the library's conventions.
navigation:
  icon: i-lucide-bot
---

Run this command in your app's repository:

```bash
npx skills add madeyoga/AuthEndpoints
```

The command copies `skills/authendpoints/` into `.agents/skills` or `.cursor/skills`.
