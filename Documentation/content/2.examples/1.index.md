End-to-end client flows against the cookie facade defaults (`/identity` management and cookie login, `/account` passkeys). Each page lists the requests in order.

Coming from `MapIdentityApi`? [Stock Identity vs AuthEndpoints](/getting-started/stock-identity-vs-authendpoints).

| Example | Use when |
| --- | --- |
| [Register a confirmed account](/examples/register-confirmed-account) | Signup must stay logged out until email confirm |
| [Reset a forgotten password](/examples/reset-forgotten-password) | User cannot sign in and needs a reset mail |
| [Two-factor authentication](/examples/two-factor) | Enable/disable authenticator 2FA, then sign in with TOTP or a recovery code |
| [Complete step-up (ReAuth)](/examples/reauth) | A manage or host endpoint requires ReAuth |
| [Sign in with a passkey](/examples/passkey-sign-in) | Passwordless login for a confirmed account |

Reference route tables live under [Modules](/modules/identity-management).
