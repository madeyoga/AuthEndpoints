### AuthEndpoints

Hosts can set how long a ReAuth step-up stays valid. `AuthEndpointsOptions.ReAuth.Lifetime` defaults to 5 minutes and applies to the ReAuth cookie, confirm `ExpiresUtc`, and header `reauthToken` together. The cookie stays non-persistent with no sliding expiration. Values must be between 1 and 60 minutes.

- `ReAuth.Lifetime` (`TimeSpan`, default 5 minutes) drives cookie `ExpireTimeSpan`, confirm `ExpiresUtc`, and `reauthToken` expiry
- Cookie remains non-persistent (`IsPersistent = false`) with `SlidingExpiration = false`
- Startup validation rejects zero, negative, over 60 minutes, and `InfiniteTimeSpan`
- Composable hosts use the same `IOptions<AuthEndpointsReAuthOptions>`
