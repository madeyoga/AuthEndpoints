### AuthEndpoints

A browser that fails external sign-in is sent to a local URL. `ErrorPath` is used when it is a relative local path. Any other value falls back to `/`. The redirect keeps `error` and `error_description` on that path.

API clients that ask for JSON receive a problem response.

No host change is required. This release adds no database migration.

The package README on NuGet is the current project README.

A published package includes build provenance. Verify the file you downloaded:

```bash
gh attestation verify <file>.nupkg -R madeyoga/AuthEndpoints
```
