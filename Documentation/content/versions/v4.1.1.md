### AuthEndpoints

Password reset and email sign-in codes are now sent only to the account's stored email address. If an account has no stored email, no code is sent.

No host change is required. This release adds no database migration.

### Packages

- **AuthEndpoints** `4.1.1`
- **AuthEndpoints.External.OAuth**, **AuthEndpoints.OAuth.GitHub**, and **AuthEndpoints.OAuth.Google** unchanged at `4.0.1`
