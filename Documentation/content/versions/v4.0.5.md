### AuthEndpoints

Startup validation reads the same property token signing reads.

A host with `Algorithm` set to `Rsa` and only `Certificate` fails at startup with `RsaKey is required when Algorithm is Rsa. Set SimpleJwtOptions.SigningOptions.RsaKey.`

A host with `Algorithm` set to `X509` and only `RsaKey` fails at startup with `Certificate is required when Algorithm is X509. Set SimpleJwtOptions.SigningOptions.Certificate.`

A host with `Algorithm` set to `Ecdsa` and no `EcdsaKey` fails at startup with `EcdsaKey is required when Algorithm is Ecdsa. Set SimpleJwtOptions.SigningOptions.EcdsaKey.`

`Rsa` with `RsaKey`, `X509` with `Certificate`, and `Ecdsa` with `EcdsaKey` still pass. A host that also sets the other key property still passes. Signing uses the property for the selected algorithm.

No host change is required when the selected algorithm already has its key. This release adds no database migration.
