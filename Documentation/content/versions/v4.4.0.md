### AuthEndpoints

**Any-caller scheme name.** `AuthEndpointsConstants.AnyCallerScheme` is `AuthEndpoints.AnyCaller`. `AnyCallerAuthenticationBuilderExtensions.SchemeName` is obsolete, removed in 5.0, and keeps the same value.

**Password removed.** `DELETE /manage/password` removes the password when another sign-in method remains, then calls `IAccountSecurityEmailSender<TUser>.SendPasswordRemovedAsync` when the account has an email. The interface method does nothing, so an existing sender still compiles. Implement it to deliver the notice. `LoggingAccountSecurityEmailSender<TUser>` logs the call and does not send mail. An account without an email gets no call. See [Identity management](/modules/identity-management).

**Account management.** `GET /manage/info` and `POST /manage/password` no longer throw when the account has no email. The info response leaves `email` null, and setting a password skips the notice. A password change through `POST /manage/info` keeps the acting cookie session and renews its ReAuth proof with the original expiry. `POST /confirmIdentity/passkeyOptions` is mapped when passkey sign-in or passkey management is registered on its own (#473).

**Routes follow registered capabilities.** Each map includes a route only when the capability that route needs is registered. The account-management map and the shared map use the same rules (#476).

**Passkey register options.** `AddPasskeyRegisterOptionsEndpoints` registers `DefaultPasskeyUserIdFactory` when no `IPasskeyUserIdFactory` is registered, so `POST /passkeys/register/options` can be mapped without the sign-up bundle. `AddPasskeyUserIdFactory` still replaces that default (#477).

No host change is required. This release adds no database migration.

### AuthEndpoints.OpenIddict

**Access-token scheme name.** `OAuthServerConstants.AccessTokenScheme` is the scheme that validates access tokens issued by this server. `OAuthServerServiceCollectionExtensions.ValidationScheme` is obsolete and keeps the same value. Token validation is unchanged.

### Packages

- **AuthEndpoints** `4.4.0`
- **AuthEndpoints.OpenIddict** `4.0.0-preview.6`. Still requires AuthEndpoints `4.3.0` or later.
- **AuthEndpoints.External.OAuth**, **AuthEndpoints.OAuth.GitHub**, and **AuthEndpoints.OAuth.Google** unchanged at `4.0.1`
