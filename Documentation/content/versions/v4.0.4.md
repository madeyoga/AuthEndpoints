### AuthEndpoints

A host whose `TUser` does not derive from `IdentityUser<TKey>` gets an error that names the user type, for example `AppUser must derive from IdentityUser<TKey> to use AuthEndpoints.`

A host that picks the `Rsa`, `Ecdsa`, or `X509` signing algorithm without its key gets an error that names the missing property and the algorithm, for example `RsaKey is required when Algorithm is Rsa. Set SimpleJwtOptions.SigningOptions.RsaKey.`

No host change is required. This release adds no database migration.

### Packages

- **AuthEndpoints** `4.0.4`
- **AuthEndpoints.External.OAuth**, **AuthEndpoints.OAuth.GitHub**, and **AuthEndpoints.OAuth.Google** unchanged at `4.0.1`
