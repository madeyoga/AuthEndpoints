### AuthEndpoints

Adds a second one-call facade for Identity bearer tokens, built from the existing management, bearer, passkey, and optional JWT modules.

- `AddAuthEndpointsBearer` / `MapAuthEndpointsBearer` map Identity `Login` (JSON access and refresh tokens) at `IdentityPath`
- `AuthEndpointsOptions.SignIn` selects `Cookie` or `IdentityBearer` (`AddAuthEndpointsBearer` forces bearer)
- Cookie facade (`AddAuthEndpoints` / `MapAuthEndpoints`) is unchanged

### Packages

- **AuthEndpoints** `3.0.2`
- **AuthEndpoints.External.OAuth** unchanged at `3.0.0-preview.3`
