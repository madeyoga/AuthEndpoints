The `AuthEndpoints` package ships an [Agent Skill](https://agentskills.io) that teaches coding agents the library's methods, routes, and options. The skill is `SKILL.md` plus one reference file per topic. An agent loads a reference file only when the task needs it.

## From the NuGet package

Releases after 4.1.0 include the skill in the package. `dotnet restore` puts it in the NuGet cache next to the assembly, so it matches the version your app restores:

```text
~/.nuget/packages/authendpoints/<version>/skills/authendpoints/SKILL.md
```

To copy the skills of your direct package references into `.agents/skills`, run [`dotnet-package-skills`](https://devblogs.microsoft.com/dotnet/delivering-skills-in-nuget-packages/) in your app's repository:

```bash
dotnet-package-skills install
```

Run it again after you upgrade `AuthEndpoints`. The copy does not update itself.

## From the repository

```bash
npx skills add madeyoga/AuthEndpoints
```

The command copies `skills/authendpoints/` into `.agents/skills` or `.cursor/skills`. That copy follows the main branch, which can describe a newer release than the one your app references.
