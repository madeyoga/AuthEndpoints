AuthEndpoints does **not** ship an MCP server. The skill is a playbook. Public docs remain at [https://madeyoga.github.io/AuthEndpoints](https://madeyoga.github.io/AuthEndpoints).

## Install into your app

```bash
npx skills add madeyoga/AuthEndpoints
```

Optionally pass `--agent cursor`. The vercel-labs/skills CLI copies from **`skills/authendpoints`**, not from `.cursor/skills`. In the consumer project that typically lands at `.agents/skills/authendpoints` or `.cursor/skills/authendpoints`.

In Cursor you can also use Customize → Rules → Remote Rule (GitHub) with `https://github.com/madeyoga/AuthEndpoints`. See [Cursor rules](https://cursor.com/docs/context/rules).

## Working on this repo

`.cursor/skills/authendpoints` is already in the tree. Cursor and Cloud Agents auto-load `.cursor/skills/` when AuthEndpoints is the workspace. They do **not** auto-load root `skills/`. No extra install.

Keep both files identical (`skills/authendpoints/SKILL.md` is the source of truth):

| Path | Role |
| --- | --- |
| `skills/authendpoints/` | Canonical / publish path. What `npx skills add madeyoga/AuthEndpoints` discovers. |
| `.cursor/skills/authendpoints/` | This-repo Cursor workspace copy. Same `SKILL.md` blob. |

Do not add `.agents/skills/` in this library repo unless you have a strong reason.
