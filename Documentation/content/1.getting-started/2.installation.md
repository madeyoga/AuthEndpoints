## NuGet package

[![nuget](https://img.shields.io/nuget/v/AuthEndpoints?label=AuthEndpoints&logo=NuGet&style=flat-square)](https://www.nuget.org/packages/AuthEndpoints/)

```bash
dotnet add package AuthEndpoints
```

The badge shows the latest published version. Release notes are in the [changelog](/changelog).

## Requirements

| Requirement | Notes |
| --- | --- |
| **.NET 10** | Target framework `net10.0` |
| **ASP.NET Core Identity** | User store and sign-in |
| **EF Core** | Identity stores and JWT refresh-token table (when JWT is enabled) |

Register a `DbContext` that works as the Identity store, such as `IdentityDbContext<TUser>` or a class that derives from it.

## Package contents

The `AuthEndpoints` package includes these modules:

- The facade: `AddAuthEndpoints`, `UseAuthEndpoints`, and `MapAuthEndpoints`.
- Identity management, cookie sign-in, and Identity bearer sign-in.
- JWT with an HttpOnly refresh cookie.
- Passkeys (WebAuthn).
- ReAuth step-up.

## Optional: External OAuth

GitHub and Google sign-in ship as preview packages. `MapAuthEndpoints` does not map them. Install the provider package that you use. Each one depends on `AuthEndpoints.External.OAuth`, which has no GitHub or Google handler of its own.

[![nuget](https://img.shields.io/nuget/vpre/AuthEndpoints.External.OAuth?label=External.OAuth&logo=NuGet&style=flat-square)](https://www.nuget.org/packages/AuthEndpoints.External.OAuth/)

```bash
dotnet add package AuthEndpoints.OAuth.GitHub --prerelease
dotnet add package AuthEndpoints.OAuth.Google --prerelease
```

These packages have their own version numbers. See [External OAuth packages](/modules/external-oauth).
