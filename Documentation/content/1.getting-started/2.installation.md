## NuGet package

[![nuget](https://img.shields.io/nuget/v/AuthEndpoints?label=AuthEndpoints&logo=NuGet&style=flat-square)](https://www.nuget.org/packages/AuthEndpoints/)

```bash
dotnet add package AuthEndpoints
```

The badge shows the latest published version. Release notes are in the [changelog](/changelog).

## Requirements

| Requirement | Notes |
| --- | --- |
| **.NET 10** | Target framework `net10.0` |
| **ASP.NET Core Identity** | User store and sign-in |
| **EF Core** | Identity stores and JWT refresh-token table (when JWT is enabled) |

Register a `DbContext` that works as the Identity store, such as `IdentityDbContext<TUser>` or a class that derives from it.

## Package contents

The `AuthEndpoints` 4.0.0 package includes these modules:

- `AddPasswordAuth`, `UseAuthEndpoints`, and `MapPasswordAuth`.
- Identity management, cookie sign-in, Identity bearer sign-in, and email-code sign-in.
- JWT with cookie or body refresh.
- Passkeys (WebAuthn).
- ReAuth step-up, including an emailed code when no stronger factor exists.
- External OAuth endpoints. Provider packages only register GitHub or Google.

## Optional: GitHub and Google

Neither facade maps external sign-in. Install the provider you use. Each one depends on `AuthEndpoints` 4.0.0, not on a separate implementation package.

```bash
dotnet add package AuthEndpoints.OAuth.GitHub
dotnet add package AuthEndpoints.OAuth.Google
```

`AuthEndpoints.External.OAuth` below 4.0.0 fails the build with `AE4000`. The 4.0.0 package of that name is a shim you can remove. See [External OAuth packages](/modules/external-oauth).
